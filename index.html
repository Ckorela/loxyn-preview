Manifeste

Quatre principes. Tenus à chaque livraison.

Ce que nous défendons quand personne ne regarde — et qui se vérifie dans le code livré.

  1. 01

    Performance d'abord

    Chaque page que nous livrons passe Lighthouse 90+. Sur smartphone d'un client en zone blanche comme sur fibre. Si elle traîne, nous reprenons. C'est le minimum que mérite votre visiteur.

    Notre engagement

    Si la page livrée scoringe < 90 sur Lighthouse, nous la reprenons sans facturer.

  2. 02

    Le code est à vous

    Le code source est livré sur votre GitHub privé, à votre nom. Hébergement libre, CMS libre. Vous pouvez nous remplacer demain — le site continue de tourner sans perte de fonctionnalité.

    Notre engagement

    Repo GitHub privé à votre nom sous 7 jours après signature. Tous les accès vous sont transférés.

  3. 03

    L'IA accélère, le jugement décide

    Nous utilisons Claude Code, Cursor et d'autres outils IA pour aller cinq à dix fois plus vite. Mais chaque ligne livrée est lue, comprise, validée. Vous achetez du code généré ET relu — la différence se voit à la livraison.

    Notre engagement

    Aucun commit n'arrive sur main sans relecture humaine. Vérifiable dans l'historique git.

  4. 04

    Une voix par projet

    Chaque site est conçu depuis une page blanche. Vocabulaire visuel propre — palette, typographie, mood. Ton et structure adaptés à votre métier. Vous obtenez à chaque fois une nouvelle voix, taillée pour vous.

    Notre engagement

    Trois directions visuelles distinctes présentées avant la moindre ligne de code.

Questions fréquentes.

Quel est le tarif ?

Le tarif dépend du périmètre : nombre de pages, fonctionnalités, intégrations, délai. Devis ferme sous 24 h ouvrées, gratuit et sans engagement.

Quel est le rôle de l'IA dans la production ?

L'IA assiste l'écriture du code, la génération de contenu et le design des composants. Chaque livrable est relu et validé par l'équipe avant transfert.

Le code source est-il transféré au client ?

Oui, intégralement. Code, fichiers design et contenus. Propriété intellectuelle complète. Reprise par un autre prestataire possible à tout moment.

Quelle maintenance après livraison ?

30 jours de support inclus : correctifs, ajustements mineurs, questions techniques. Au-delà, maintenance facturable au taux horaire ou en forfait mensuel.

Intégration avec les outils existants ?

Oui : CRM, messagerie, logiciel comptable, ERP, catalogue produits. Intégration via API, webhooks ou scripts.

L'hébergement est-il à la charge du client ?

Configuration assurée par Loxyn (Cloudflare ou Vercel selon le projet). Transfert du nom de domaine inclus. Facturation hébergement au choix : directe ou refacturée via Loxyn.

Loxyn est-elle basée à Lyon ?

Oui. Siège social Tour TO-LYON, 49 boulevard Vivier Merle, Lyon 3e. Rendez-vous physique possible sur Lyon. Intervention à distance partout en France.
